# 设置与排查

[返回首页](../README.zh-CN.md) · [English](troubleshooting.md)

## 按了快捷键，没有通知

先分清是**没存成功**，还是**存了但没显示通知**。

1. 在 Finder 的“前往文件夹”输入 `~/inbox`，查看是否出现刚保存的文件。也可在终端运行：

   ```bash
   "$HOME/.local/bin/side-inbox" list
   ```

2. 如果文件已出现，保存功能正常。检查系统的通知与专注模式设置，以及实际负责显示通知的应用是否被允许通知。
3. 如果没有新文件，重新复制一段不同的测试文字，在「快捷指令」中手动点击“存到收件箱”的运行按钮。没有复制新内容、已有相同内容、或剪贴板不是文字时，快速保存会跳过。
4. 手动运行成功、快捷键失败，说明需要检查按键映射、组合键冲突或当前应用是否能触发快捷指令。可在另一个应用中比较。复制用的 Command 键正确，不代表 Control、Option 的映射也符合键帽标注。
5. 手动运行也失败，检查“允许运行脚本”、脚本路径和显示的错误；可用下方命令单独测试保存。**它会保存当前剪贴板，先复制无敏感信息的测试文字。**

   ```bash
   "$HOME/.local/bin/side-inbox" quick
   ```

快捷指令可能不能在所有应用中接收快捷键。手动运行可作为临时入口，不需要给主对话发消息。项目正探索原生全局快捷键方案；个人环境试验成功不代表已作为通用版本发布。

## 自动生成快捷指令失败

生成器依赖 `/usr/bin/python3` 和 macOS 的 `shortcuts sign`。即使生成失败，命令和已检测到的 agent 技能可能已经装好。

可以在「快捷指令」中新建快捷指令，加入“运行 Shell 脚本”，内容填写：

```bash
"$HOME/.local/bin/side-inbox" quick
```

命名为“存到收件箱”，在详情中设置快捷键，并开启“允许运行脚本”。首次先点击运行验证。

仅安装命令和技能、跳过快捷指令生成：在仓库目录运行：

```bash
./install.sh --no-shortcut
```

## Claude Code 或 Codex 找不到 merge

安装器检测到 `~/.claude`、`~/.codex` 目录后，才为相应工具安装技能。先完成对应工具的初始化，再重新运行安装器；随后重新打开会话或应用，让它重新发现技能。

| 工具 | 技能目录 | 调用方式 |
|---|---|---|
| Claude Code | `~/.claude/skills/merge/` | `/merge` |
| Codex | `~/.codex/skills/merge/` | `$merge` |

安装器不会覆盖不属于本项目的同名技能；如果提示跳过，请检查冲突。远程或云端 agent 还需要能够访问这台 Mac 的收件箱，不能只凭命令名称就跨机器取文件。

## 复制的内容不对，或者保存的是上一段

剪贴板检查只能减少重复保存，无法验证你是否选中了想要的内容。检查文件或通知里的标题。需要预览再确认时，可使用 `/inbox` 或 `$inbox`，但预览和确认会进入当前对话。

快速保存会比较剪贴板计数，以及当前收件箱里的文件内容。这不是完整的剪贴板历史管理器；已经归档或删除的文件不会继续参与内容去重。对重启后的计数、密集连续触发或并发保存，不应依赖它提供强保证。

## 可以换收件箱位置吗？

命令支持 `SIDE_INBOX_DIR`，但安装器和技能默认使用 `~/inbox`。只改快捷指令会造成“存到一个目录，去另一个目录找”。目前建议保留默认位置。

若需要自定义，必须同时调整快捷指令的环境变量，以及两个 agent 的 `inbox`、`merge` 技能中的目录；这不是现成的全局设置开关。自动按项目分箱、来源标签、跨机器同步目前也没有内置支持。

## 更新与卸载

在没有自定义改动的仓库中，可拉取更新，再更新命令和技能。已有快捷指令可以继续调用原路径：

```bash
git pull --ff-only
```

```bash
./install.sh --no-shortcut
```

若本地改过技能，更新前先保留自己的版本；安装器会替换带本项目标记的技能。

卸载：

```bash
./uninstall.sh
```

它会删除命令和本项目安装的技能，**保留 `~/inbox` 中的内容与记录**。在「快捷指令」里手动删除“存到收件箱”和它的按键绑定。个人试装的额外助手应按该助手的安装方式单独卸载。

仍有问题时，请[提交 issue](https://github.com/zaozhiyi/side-inbox/issues/new/choose)，附 macOS / 应用版本、键盘类型、实际按键，以及手动运行是否成功；使用无敏感信息的示例。
